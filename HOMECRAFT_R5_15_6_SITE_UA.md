# Home Craft R5.15.6 — оформлення, безпека, SEO

**База:** R5.15.5 SITE. Java-моди, авторизаційні API-маршрути, формати токенів і робочі `.env`/`config` не змінювалися. Версія Node-пакета: `1.2.3`.

## Оформлення та доступність
- `public/theme.css` — окрема тема для контрасту, типографіки, карток, кнопок, форм, статичних сторінок і меню. Старі специфічні стилі залишено в `styles.css` задля сумісності.
- Мобільна навігація на ширинах до 900 px з кнопкою, `aria-expanded`, закриттям через Escape та без приховування вмісту, коли JavaScript вимкнений.
- Спрямований фокус для клавіатури, skip link, більші зони натискання, коректні `label` для полів входу/реєстрації, підказки про помилки для screen readers.
- Анімація зірок обмежена до 30 FPS на мобільних і 45 FPS на великих екранах; `prefers-reduced-motion` поважає системні налаштування.
- Прибрано демонстраційні «новини» з вигаданими лічильниками: сторінка поки містить посилання на реальні анонси в Discord і `noindex`.

## Пошукова оптимізація
- Публічні сторінки `/`, `/download`, `/map`, `/status`, `/support`: унікальні `title`, `description`, `canonical`, Open Graph, `twitter:card`.
- `public/robots.txt`, `public/sitemap.xml` містять лише публічні маршрути. `noindex` для входу, реєстрації, профілю, адміністратора й тимчасової сторінки новин.
- Головна має JSON-LD `WebSite`, який дозволений за точним SHA-256 у CSP. **Після редагування тексту цього JSON-LD потрібно оновити CSP hash** в `server.js`.
- `.html` URL перенаправляються на канонічні адреси. Sitemap не містить фальшивих lastmod; жодної обіцянки автоматичного потрапляння до Google.
- Продукційний домен зашитий у SEO-метаданих: `https://homecraft-mc.pp.ua`. Для іншого домену перед публікацією оновити всі canonical/OG, sitemap та robots.

## Захист і обмеження
- Відповіді Node отримують CSP (скрипти лише власного походження, окремий hash для JSON-LD), `X-Frame-Options: DENY`, `nosniff`, `Permissions-Policy`, `Referrer-Policy` і HSTS на HTTPS-сайті.
- `style-src 'unsafe-inline'` **поки залишається**, бо дерево талантів генерує вбудовані `style` позиціонування. Для суворішої CSP потрібен окремий рефакторинг `app.js`.
- Для POST/PUT/PATCH/DELETE із `Origin` перевіряємо його збіг з адресою сайту; `Sec-Fetch-Site: cross-site` відхиляється. Java-клієнти не надсилають `Origin` і не блокуються. Це доповнення до HttpOnly+SameSite cookie, а не заміна авторизації.
- IP для rate limit береться із TCP-з'єднання за замовчуванням. `HOMECRAFT_TRUST_PROXY=true` допустимий **тільки** за довіреним проксі, який **перезаписує** X-Forwarded-For. Наш Nginx налаштований на `$remote_addr`, а не `$proxy_add_x_forwarded_for`.
- На Cloudflare-проксі `$remote_addr` може бути IP вузла Cloudflare, а не людини. Для коректних обмежень за кінцевим клієнтом потрібно налаштувати Nginx real_ip із актуальним списком мереж Cloudflare **та захистити origin від прямого доступу**. Без цього не можна вважати rate limiting ідеальним.
- Жодна конфігурація не гарантує захист від DDoS; перевірте Cloudflare WAF, резервні копії, права конфігів та відповідність серверних секретів.
- Додано захист від помилкових cookie, небезпечних шляхів до статичних файлів, невідомих HTTP-методів і надмірного росту Map лімітів.
- Виправлено обробку OpenSSL `-checkhost` у скрипті деплою: чужий сертифікат відхиляється з поясненням, а не сирим винятком.

## Встановлення без втрати даних
1. Резервна копія `data/`, `config/`, `.env`, Docker override, nginx конфіг.
2. Замінити тільки програмні файли сайту (не переносити `data/`, `config/`, `logs/` і секрети з ZIP).
3. `sh deploy.sh` з поточного каталогу `/srv/mc-site`. Скрипт уже містить процедуру резервного копіювання та rollback, але це не замінює власну копію.
4. Перевірити у браузері `/`, `/login`, `/map`, `/download`, `/status`, мобільне меню, `https://homecraft-mc.pp.ua/robots.txt` і `/sitemap.xml`.
5. Перевірити авторизацію Minecraft і клієнта після деплою, не змінюючи JAR-файли.
6. Запустити зовнішню перевірку Google Search Console і PageSpeed / Lighthouse на **живому** домені: швидкість та індексацію не можна довести за вихідниками.
