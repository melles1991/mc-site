Адони Home Craft

Тут показуються тільки наші зібрані Home Craft JAR-адони, які не є server-only і реально потрібні клієнту: GUI, клієнтські події, рендери, моделі або візуальні ефекти.

HomeCraft Launcher — Java для Windows та Linux

Завантажуй і оновлюй клієнтські моди автоматично. Лаунчер порівнює SHA-256, перевіряє файли та зберігає резервні копії попередніх версій.

Завантажити HomeCraft Launcher

Java 21+ (можна Java 25). В архіві готовий HomeCraftLauncher.jar, вихідний код Java, запуск для Windows (.bat) та Linux (.sh). Гру запускає твій Minecraft/Prism Launcher.

Обовʼязкові клієнтські адони

Сторонні бібліотеки, залежності, resource pack і server-only моди не показуються. Мапа сайту залишається тільки на сервері.
