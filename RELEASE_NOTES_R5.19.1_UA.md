# Home Craft SITE R5.19.1 — спільний макет та сторінки гравця

База: R5.19.0 (UI, email recovery, existing backend retained).

## Виконано

- 13 HTML-сторінок мають спільний контейнер, навігацію, заголовки та відступи з `public/site-layout.css`.
- `layout/header.html` та `layout/footer.html` — єдине джерело для спільних компонентів. `npm run layout:sync` застосовує їх на сторінках. `npm run layout:check` перевіряє синхронізацію.
- Сторінка `/download`: лаунчер або ручне встановлення, прості 4 кроки, список модів із серверного API, людські тексти замість технічної діагностики.
- Сторінка `/profile`: навігація розділами, огляд акаунта, прив'язка Minecraft, попередній перегляд скіну й плаща, перехід до відновлення пароля.
- Дані користувача, інтеграції, API, список модів і відновлення пароля R5.19.0 залишені без змін у серверних маршрутах.
- Показувана рекомендована версія NeoForge оновлена до 26.3.0.97 відповідно до обраної користувачем збірки. Перед бойовим розгортанням перевірити доступність відповідного інсталятора і його збіг із сервером.
- URL файлів зі списку клієнтських модів тепер обмежено внутрішніми шляхами `/client-mods/...`.

## Важливо

- Архів лише з кодом сайту; **не** містить приватних файлів `.env` або баз користувачів.
- Наявні `data/` і `.env` не перезаписувати при оновленні.
- Синтаксис JavaScript перевірено через `npm run check`; структура сторінок і синхронізація шаблонів перевірені автоматично.
- Повноцінний візуальний smoke-test у браузері був недоступний у цьому середовищі: перед продакшеном перевірити мобільні екрани, вхід, профіль із реальним акаунтом та завантаження доступних JAR.
