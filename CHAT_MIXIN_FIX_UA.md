# R5.18.14 — виправлення завантаження HomeCraft Chat

Виправлено помилку `IllegalClassLoadError`: `ChatClientEvents is in a defined mixin package ... and cannot be referenced directly`.

Причина: конфігурація `homecraft-chat.mixins.json` оголошувала весь пакет звичайних клієнтських класів `ua.homecraft.chat.client` пакетом Mixin. Під час пошуку підписників подій NeoForge намагався завантажити `ChatClientEvents`, а Mixin забороняв таке завантаження.

`ChatScreenAccessor` перенесено в окремий пакет `ua.homecraft.chat.mixin.client`; оновлено його імпорт і конфігурацію. Звичайні клієнтські класи залишилися поза простором Mixin. Версія мода — **0.1.2-alpha.26.3.3+mc26.3-neoforge**.

## Як встановити

1. Закрий гру та зупини сервер перед заміною їхніх модів.
2. Прибери попередній `homecraftchat-*.jar` із відповідної папки `mods`.
3. Поклади новий JAR чату з цього архіву на клієнт і сервер. Не залишай дві версії одночасно.
4. Запусти гру та сервер знову.

Для власника сайту: встанови архів сайту R5.20.1. Він містить новий JAR та оновлений список перевірених файлів. Після цього HomeCraft Launcher 3.1 завантажить заміну через звичайну перевірку модів. Лаунчер перевіряє вміст за SHA256, тому повторне встановлення лаунчера не потрібне.

## Що перевірено

- Мод зібрано Java 25 для Minecraft 26.3 / NeoForge 26.3.0.99 в окремому чистому каталозі без кешу компіляції.
- У готовому JAR є лише новий accessor; старого класу в пакеті `client` немає.
- Ручна перевірка справжнім `MixinConfig.packageMatch` відтворює помилку на старому JAR і проходить на новому для всіх 27 класів. Перевірка не запускає графічний клієнт.
- Аналогічна перевірка 63 класів Auth також проходить.
- 32 перевірки станів клієнтського чату та 35 перевірок політики каналів пройдені вручну.
- 34 перевірки реального HTTP-сайту й Linux/Java-лаунчера з новим Chat пройдено повторно: встановлення, оновлення, контроль SHA256, відмова при неповній збірці.
- У скриптах збірки не додано запуску автоматичних тестів.

Повний запуск Minecraft із графікою в цьому середовищі не перевірявся. Зміна виправляє конкретний конфлікт пакетів зі скриншота; налаштування, історія чату та правила доступу до гільдій не змінювалися.
