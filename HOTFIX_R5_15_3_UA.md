# HomeCraft R5.15.3 — автоматичні конфігурації NeoForge 26.3

## Що змінено

- Усі чотири HomeCraft моди створюють свої серверні `.properties` самі при запуску Minecraft.
- Auth/Guilds/Spawn Protection на фізичному клієнті створюють окремі клієнтські конфігурації (без `serverSecret`). Realtime Map — серверний мод.
- Відсутні ключі **дописуються в кінець файла**. Наявні ключі, значення, коментарі й форматування не переписуються на кожному запуску.
- Для гільдій прибрано автоматичне перепризначення старих значень талантів/лімітів під час завантаження. Початкові значення нових ключів як і раніше беруться з `ensureDefaults`; випадковий непогоджений із сайтом гільдійний секрет більше не створюється.
- Загальний `config/homecraft-connection.properties` створюється модом: більше не потрібно встановлювати порожній шаблон із ZIP.
- Для конкретного випадку **порожнього** `serverSecret` у `homecraft-connection.properties` можлива одноразова безпечна міграція: за наявності одного узгодженого заповненого секрету в локальних конфігураціях Auth/Guilds/Map мод відновить його, попередньо створивши `.before-r5.15.3.bak`. Непорожні секрети не замінюються. Конфліктні секрети не узгоджуються автоматично.
- Виправлення R5.15.2 проти `ConcurrentModificationException` у Home Craft Auth залишене.

## Серверні файли

- `config/homecraft-connection.properties` — спільна адреса сайту та секрет серверного API.
- `config/homecraft-auth.properties` — авторизація, спавн, скрині.
- `config/homecraft-guild.properties` — гільдії, NPC, території, таланти.
- `config/homecraft-map.properties` — мапа.
- `config/homecraft-spawn-protection.properties` — захищена зона спавну.

## Клієнтські файли

- `config/homecraft-auth-client.properties`
- `config/homecraft-guild-client.properties`
- `config/homecraft-spawn-protection-client.properties`

Клієнтські файли є окремими конфігураціями для локальних налаштувань. Наявний ігровий GUI наразі отримує адресу API із серверного пакета; клієнтський `siteUrl` не перевизначає серверний URL. Це зроблено, щоб клієнт не підмінив адресу авторизації сервера.

## Важливо про авторизацію

Minecraft-сервер і окремий сайт мають знати **один і той самий `HOMECRAFT_SERVER_SECRET`**. Мод **не може безпечно сам отримати секрет із віддаленого сайту без початкової довіри**. Якщо немає секрету ані в оточенні, ані в старих налаштуваннях, згенерований файл матиме `serverSecret=` (порожній), а авторизація лишиться заблокованою з попередженням у журналі. Не потрібно публікувати секрет у чаті, репозиторії або у клієнтських JAR.

Якщо секрет сайту відрізняється від збереженого на Minecraft-сервері, потрібно один раз узгодити їх (безпечним приватним каналом, через змінну оточення на сервері або експорт з адмінпанелі сайту), потім перезапустити сервер. **Секрет не можна просто випадково згенерувати незалежно на двох серверах.**

## Встановлення

1. Зробіть бекап світу, `config/` та даних сайту.
2. Зупиніть сервер; видаліть лише **старі JAR HomeCraft** з `mods/`, решту модів не чіпайте.
3. Перенесіть чотири JAR із папки `mods/` нового Minecraft-пакета в `mods/` сервера.
4. Замініть клієнтські моди трьома JAR з `client-mods/`, прибравши старі версії.
5. **Не копіюйте шаблон** `homecraft-connection.properties` із попередніх релізів. Не видаляйте поточний `config/`.
6. Запустіть Minecraft; перевірте журнал `[Home Craft Config]` та нові ключі.
7. Перевірте успішний логін і тайм-аут гравця без авторизації (попередній серверний краш не повинен повторитися).

## Перевірено / не перевірено

- Java 21: окремі класи-генератори компілюються і працюють у тестовій тимчасовій папці.
- Перевірено створення файлів, доповнення нових ключів, незмінність старих значень, повторний запуск без змін, окремі клієнтські файли та відновлення порожнього секрету на **копії** наданого `config.zip`.
- У Java 25 JAR застосовано точковий патч викликів у байткоді модів (без перескладання Minecraft API). Структуру викликів перевірено `javap`, ZIP/JAR — перевіркою цілісності.
- **Повний запуск NeoForge 26.3 на Java 25, реальний мережевий логін і внутрішній сервер одиночної гри тут не перевірялися**. Це не підтверджений production-реліз.
