# R5.19.2 — повний клієнтський комплект і Launcher 3.1

Сайт публікує Auth, Chat, Guild, Spawn Protection та Realtime з перевіреного пакета R5.18.13a. П'ять справжніх JAR включено в `client-mods/`. Map не публікується клієнтам. Realtime входить у комплект за явним правилом розповсюдження, попри серверні залежності в його metadata.

Список ручного завантаження й `/api/launcher/manifest` використовують однакові п'ять ID. Старі налаштування include/requiredIds лише для трьох модів більше не приховують Chat і Realtime. Файл `client-mods/client-pack.json` задає конкретні опубліковані файли, розміри й SHA256. Залишені старі JAR при накладанні архіву не приховають поточні збірки як дублікати. Невідповідність опублікованому комплекту робить набір неготовим.

За замовчуванням сайт читає `client-mods/`. Якщо HOMECRAFT_SERVER_MODS_DIR налаштовано явно, перевір, що це потрібна папка. Docker Compose уже використовує `/app/client-mods`. Оновлюй `client-mods/` разом із каталогом client-pack.json як один реліз. Не змінюй список опублікованих файлів без перевірки їхніх modId та хешів.

Сторінка `/download` містить два завантаження:

- `/launcher/HomeCraftLauncher.jar` — готовий Java 17+ JAR, працює у Windows і Linux.
- `/launcher/HomeCraft-Launcher-Java.zip` — той самий JAR, інструкція та Windows/Linux-скрипти.

За `/launcher/HomeCraft-Launcher-Source.zip` доступний відповідний вихідний код. Усі три файли фізично включено в public/launcher, отже після розгортання це не порожні посилання. Рекомендований NeoForge — 26.3.0.99, мінімальний діапазон 26.3.0.97–26.4.

Launcher 3.1 встановлює відсутні моди й оновлює старі. Те саме виконується автоматично перед «Грати». Лише після перевірки й підготовки комплекту відкривається налаштований Minecraft/Prism Launcher. На Linux: `sh start-linux.sh` або `java -jar HomeCraftLauncher.jar`.

Для оновлення розпакуй website зі збереженням своїх config/data/logs та виконай чинний `./deploy.sh`. Цей архів не означає автоматичне розгортання на живому домені. Базові дані користувачів і конфігурації не замінюються демонстраційними даними; приватний секрет лишається твоїм.

Виконано 34 перевірки реального локального HTTP-сайту/лаунчера, 14 Swing-перевірок, 15 регресійних перевірок модів/графіки, npm check та layout:check. Тести запускаються лише вручну. Реальний Minecraft і нативне вікно Windows не запускалися; живий домен не змінювався.
